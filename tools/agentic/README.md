# tools/agentic

Deterministic helper scripts used by the Agentic System Kit.

- `repo_snapshot.py` → creates `artifacts/_local/repo_snapshot.md`
- `project_state_refresh.py` → updates `project_state/_generated/*` and can create `project_state.zip` under `artifacts/_local/gpt_bundles/`
- `gpt_bundle.py` → creates `gpt_bundle.zip` for GPT review under `artifacts/_local/gpt_bundles/`
